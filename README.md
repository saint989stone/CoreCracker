Описание проекта:

Приложение работает на основе значений получаемых метрик от Zabbix сервер. Web формы заполнения пользователем данных выполнены на основе шаблонизатора WEB страниц Jinja2.

В директории app, содержится экземпляр web приложения на основе фреймворка Flask.

В директории templates содержатся шаблоны WEB страниц Jinja2 на базе страницы base.html

__init__.py - модуль инициализации приложения Flask, содержащий экземпляры всех установленных расширений Flask

email.py - модуль содержащий функции по работе с e-mail

errors.py - модуль обработки ошибок от WEB сервера

forms.py - модуль хранения классов WEB форм

models.py - модуль содержащий модели объектов SQLAlchemy ORM

parser.py - модуль разбора получаемых от пользователя триггеров из Zabbix

pattern.py - модуль содержащий списки регулярных выражений и шаблоны словарей значений получаемых от Zabbix сервера.

regular.py - функции по поиску регулярных выражений

routes.py - модуль маршрутизации запросов от WEB страницы

zabxmax.py - модуль с функциями по работе с ZabbixAPI

В директории migrations содержатся файлы миграции интсрумента миграции базы данных SQLAlchemy Alembic

В директории logs содержатся логи работы приложения

В директории venv содержатся файлы виртуального окружения Python c установленными модулями

config.py - модуль содержащий конфигурации объекта приложения Flask

app.db - объект базы данных SQLite

corecracker.py - скрипт запускающий объект приложения Flask
